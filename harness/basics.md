# 기본 동작 점검

문단 왼쪽 기준선입니다.

- 첫 번째 항목
- 아주 긴 항목입니다. 줄이 넘어가면 두 번째 줄이 불릿 아래가 아니라 첫 줄 텍스트 시작 위치에 맞춰 정렬되어야 합니다. 그래야 읽기 편합니다.
  - 두 칸 들여쓴 중첩 항목
    - 네 칸 들여쓴 세 번째 단계
- 마지막 항목
  이어지는 줄(같은 항목의 문단)

1. 번호 하나
2. 번호 둘인데 이것도 아주 길게 써서 줄바꿈이 되었을 때 번호 뒤 텍스트 위치에 맞춰 정렬되는지 확인합니다. 한 줄을 더 넘기도록 문장을 조금 더 붙입니다.
   1. 세 칸 들여쓴 중첩 번호
10. 두 자리 번호

- [ ] 할 일 하나
- [x] 끝난 일인데 길게 써서 줄바꿈이 되었을 때도 체크박스 오른쪽 텍스트 위치에 맞춰 정렬되는지 확인합니다. 한 줄을 더 넘기도록 문장을 조금 더 붙입니다.

1. 설치합니다:

   ```sh
   npm install
   ```

2. 실행합니다.
